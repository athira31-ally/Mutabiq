Trakheesi Compliance Detector

Checks a Dubai property listing for Trakheesi advertising violations before it goes live — DLD fines start at AED 50,000.

One API call runs three checks on the listing photos and combines them into a pass / review / fail report.

Permit OCRReads the permit number from the image and matches it to the ad.
Watermark detectorYOLOv8n, exported to ONNX Runtime — flags other brokers' logos.
Reused photosPerceptual hashing catches the same photo posted by another agent.
Rule engineTurns the findings into a DLD-style pass / review / fail verdict.

Honest limits. The watermark model was trained on synthetic brokerage wordmarks and is best at small text marks like the ones in its training data; large stylised logos are the next thing to train on. It is tuned for recall (a false alarm only means “review”), so busy photos can occasionally be flagged. OCR here is Tesseract; the service can switch to Azure AI Vision with one setting. The reuse index resets when the app scales to zero.
