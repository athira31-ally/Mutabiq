Mutabiqمطابق

Arabic for compliant — a Trakheesi compliance checker for Dubai property listings

Checks a Dubai property listing for Trakheesi advertising violations before it goes live — DLD fines start at AED 50,000.

One API call runs these checks on the listing photos and combines them into a pass / review / fail report.

Permit checkReads the printed permit number or the Trakheesi permit QR code, and matches it to the ad.
Watermark detectorYOLOv8n, exported to ONNX Runtime — flags other brokers' logos.
Reused photosPerceptual hashing catches the same photo posted by another agent.
Rule engineTurns the findings into a DLD-style pass / review / fail verdict.

…or check a real listing

Paste a Bayut or Property Finder link. Portals often block automated reading (Bayut does), so for those also upload the page as a PDF: open the listing, press Cmd+P (Ctrl+P), choose Save as PDF.

Upload one or more listing photos. Each photo is read for a printed permit number and scanned for a permit QR code.

Result

Pick a sample or upload a listing to see the compliance report.

Honest limits. The permit QR is decoded and checked against the ad, but its signature can only be verified by following the link (the portal/DLD holds the key). The watermark model was trained on synthetic brokerage wordmarks and is best at small text marks like the ones in its training data; large stylised logos are the next thing to train on. It is tuned for recall (a false alarm only means “review”), so busy photos can occasionally be flagged. OCR here is Tesseract; the service can switch to Azure AI Vision with one setting. The reuse index resets when the app scales to zero.
